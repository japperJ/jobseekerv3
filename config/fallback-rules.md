# Listing fallback rules

This file contains editable fallback vocabulary used only when the Copilot
model cannot parse a job listing. Keep these terms broad enough to support
different job listings, and add role-specific terms here instead of changing
TypeScript code.

## Supported roles

- Solution Architect
- Cloud Architect
- Enterprise Architect
- IT Specialist
- Technical Account Manager
- Pre-Sales Architect
